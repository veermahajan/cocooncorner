Site Analytics

Where to see how the site is used and how often the lesson plans are downloaded.

This page is unlisted, not private. It is kept out of the navigation and carries a noindex tag so search engines skip it, but anyone with the URL can open it — and the site’s source repository is public, so the address is discoverable there. Never put passwords or API keys on this page.

GoatCounter — downloads

Counts every click on a download link: each grade-level curriculum PDF, the Teacher Education Packet, and the slide decks. Each one appears under Events named download-<filename>. Also records page views. No cookies, no personal data.

Open GoatCounter →

Vercel — page views

Page views and visitor counts per page, straight from the host. Useful for seeing how many people reach the curricula page at all. On the Hobby plan the history window is one month and it cannot record download clicks — that is what GoatCounter is for.

Open Vercel Analytics →
Setup

Two steps to switch this on

  1. Vercel: in the Vercel dashboard open the project → Analytics → Enable. The tracking tag is already on every page, so nothing else is needed.
  2. GoatCounter: create a free site at goatcounter.com, then put its code (the MYCODE part of MYCODE.goatcounter.com) into GOATCOUNTER_CODE at the top of site.js. Until it is set, nothing loads and no requests are made.
Reading the numbers

Two things to keep in mind

  1. Downloads are counted as link clicks, not file requests. The curricula page previews each PDF inline, so counting raw file requests would count previews as downloads.
  2. Nothing was recorded before this was set up. Both tools start from zero; earlier downloads cannot be recovered.

This page is excluded from both trackers, so checking your own stats does not inflate them.
