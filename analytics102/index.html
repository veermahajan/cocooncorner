Three things worth knowing. Downloads are counted as clicks on a download link, not as file requests — the curricula page previews each PDF inline, so counting requests would score previews as downloads. Figures are cached by GoatCounter for up to four hours, so a download you just made may not appear straight away. And nothing was recorded before this was set up, so both tools start from zero.

Visits to this page are excluded from tracking, so checking your own numbers does not inflate them. Vercel’s figures are not shown here — reading them needs a private API key, which cannot go in a public repository — so use the dashboard link above for those.
